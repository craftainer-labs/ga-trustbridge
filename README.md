# template-fastapi

> [!NOTE]
> This repository is vibe coded with [Claude](https://claude.com/product/claude-code).

A template repository for FastAPI projects, built around a devcontainer
setup composed from independent, swappable pieces. See
[`docs/TEMPLATE.md`](docs/TEMPLATE.md) for contents, getting started,
checks, template sync, versions/config, and code style — everything
about this repository that's identical across every instance of this
template. Once instantiated, rename this file's title and description
to the actual project's; `docs/TEMPLATE.md` stays as-is and is what
`.github/workflows/template-sync.yml` keeps up to date.
