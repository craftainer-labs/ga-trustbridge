# NFR-0032. The admin API v1 is versioned under `/admin/v1`, with a served and snapshotted OpenAPI spec that cannot drift

## Status

Accepted. Implemented.

## Attribute

Maintainability, compatibility (versioned API), security (no unguarded route).

## Description

- **One versioned base path.** Every admin route is under `/admin/v1`; none exists at an
  unversioned path or under the template's `/crud`, `/audit` or `/mock`. A breaking change
  exists only under a new version prefix ([NFR-0001](NFR-0001-url-prefix-versioning-policy.md)).
- **A spec that matches the code.** The OpenAPI document of the admin router alone (no template
  route) is served authenticated at `/admin/v1/openapi.json` from one immutable body and is
  committed as `docs/openapi/admin-v1.json`. CI fails when the generated spec differs from the
  snapshot; `python -m trustbridge.admin.spec > docs/openapi/admin-v1.json` regenerates it, and
  ADR 0033 says the snapshot is attached to each release, but no release job does that yet (see
the gaps below).
- **Uniform contract.** Every error is `application/problem+json` with `type`, `title`,
  `status`, `detail` and `instance` ([NFR-0015](NFR-0015-exception-detail-redaction.md)). Lists
  use the cursor envelope `{items, next_cursor}` with `limit` 50 by default and 200 at most
  (422 above); a cursor resumes without repeating or skipping rows. Request bodies of
  non-safe methods are bounded (413 over the bound, before authentication for an anonymous caller).
- **Guard order.** A walk of the mounted router fails any route without authentication, the rate
  limit and the role check in that order, any mutating route without an audit emitter or the
  mutation bucket, and any non-API mount under the admin prefix.

## Source

Enterprise baseline row EB-11 (versioned APIs: OpenAPI with rate limiting and `Retry-After`) of
the plan `docs/plans/2026-10-craftainer-labs-apps.md`; user decisions 1 and 6 in
[ADR 0033](../adrs/0033-admin-api-v1-rbac-and-limits.md) (base path, cursor pagination, served
spec plus snapshot). Stakeholder: API consumers. Builds on
[NFR-0001](NFR-0001-url-prefix-versioning-policy.md), [NFR-0011](NFR-0011-server-side-authorization-only.md)
and [NFR-0012](NFR-0012-routes-public-by-default.md).

## Verification

Unit tests run in the Checks workflow's prek job (pytest, 100% coverage gate).

- Drift test: `test_the_committed_snapshot_equals_the_generated_spec` in
  `tests/trustbridge/admin/test_spec_unit.py`, with
  `test_the_spec_lists_only_admin_routes_and_needs_a_token`,
  `test_the_snapshot_documents_every_route_of_adr_0033_and_0034`,
  `test_the_spec_is_served_from_one_immutable_body` and
  `test_the_regeneration_command_prints_the_snapshot`.
- Router walk and versioning (invariants 1, 13, 21):
  `test_every_admin_route_authenticates_limits_then_checks_the_role_under_v1`,
  `test_unknown_route_under_v1_is_a_typed_404`, `test_errors_off_the_admin_path_keep_the_templates_type`
  in `tests/trustbridge/admin/test_routes_unit.py`; the `test_the_mutation_walk_*` tests in
  `tests/trustbridge/admin/test_guards_unit.py`.
- Errors and pagination (invariants 9, 10): `test_a_bad_limit_is_a_422_problem`,
  `test_a_malformed_cursor_is_a_400_problem`, `test_hosts_page_without_repeats_and_unknown_host_is_404`
  and `test_tenants_page_and_cursor` in `test_routes_unit.py`; `tests/trustbridge/admin/test_cursor_unit.py`;
  `test_tenant_lists_are_scoped_ordered_and_keyset_paged` in `test_reads_integration.py`.
- Body bound: `test_a_content_length_over_the_bound_is_a_413_before_the_body_is_read` and
  `test_an_unauthenticated_oversized_post_is_a_413_before_authentication` in `test_guards_unit.py`.
- No secret in responses (invariant 8): canary tests in `tests/trustbridge/admin/test_reads_unit.py`,
  `test_registration_unit.py` and `test_rotate_unit.py`;
  `test_deliveries_never_show_headers_and_give_the_payload_to_operators_only` in `test_reads_integration.py`.

Known gaps: invariant 12 ("adding a route does not change an existing route's schema") has no
automated test beyond the snapshot diff a reviewer reads; the snapshot is regenerated by hand and
no workflow or Makefile target attaches it to a release, so that part of ADR 0033 is
unimplemented; a pre-authentication request-memory bound
and a request timeout are named in the plan as measurements owed to NG6g and are not measured.
